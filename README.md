# Age Calculator by Kali Yuga

A free, responsive age calculator built with plain HTML, CSS and JavaScript.

## Deploy
1. Upload all files in this folder to the root of a GitHub repository.
2. Import the repository into Vercel.
3. Use the default settings and deploy.
4. Replace `YOUR-DOMAIN.vercel.app` in `index.html`, `robots.txt`, and `sitemap.xml` with your actual Vercel domain.
5. Redeploy, then submit `https://YOUR-DOMAIN.vercel.app/sitemap.xml` in Google Search Console.

No build command or framework is required. The site is static and works on Vercel's free Hobby plan subject to its current terms.
